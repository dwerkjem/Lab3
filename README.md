# Fountain View Hall

## Running Project

### Pre-run Install

#### Using uv (recommended)

Follow the [uv install instructions](https://docs.astral.sh/uv/getting-started/installation/) and run:

```cmd
uv sync
````

#### Using pip

```cmd
py -m pip install -r requirements.txt
```

### Running After Install

#### Using uv (recommended)

```cmd
uv run tui
```

#### Using Python

```cmd
py src/lab3/main.py
```
